IoT telepresence robot for remote medical consultation

A working robot on ESP32 and Arduino that streams body temperature, heart rate and SpO2 to a live web dashboard at a 5-second data refresh interval.

Problem

Where medical resources are limited, a doctor cannot always be in the room. A mobile robot with live vital signs lets a doctor consult and monitor a patient remotely.

What I did

  • Designed and built the robot on ESP32 and Arduino.
  • Integrated body temperature, heart rate and SpO2 sensing with a live web dashboard.
  • Implemented UDP-based telemetry from the remote unit at a 5-second data refresh interval, choosing a connectionless protocol to minimise overhead on constrained embedded hardware.

Tools

  • ESP32
  • Arduino
  • sensor integration
  • UDP telemetry
  • web dashboard
